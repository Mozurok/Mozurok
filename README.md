**[Fhorja](https://fhorja.dev)** is an open-source workflow for AI coding agents that I design and build. Plans, decisions, and task state live as files on disk instead of in chat history, so a session can stop and the next one picks up where it left off. On an attended run with a git remote, the chain goes from `task-init` to a pushed task branch and a draft pull request that lists every decision the agent made without you and anything it could not verify. Merging stays with you.

Release v2.1.0 has 98 commands and runs a wave of independent slices in parallel. In the one measured run, a wave of three slices finished about 62 s after dispatch, against 173.6 s run one after another. Those slices took about a minute each, and every wave carries a fixed cost of about 45 s. Markdown, bash, and a small Python helper, MIT licensed. Built and dogfooded solo.
